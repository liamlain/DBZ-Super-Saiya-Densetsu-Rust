# Android Traditional Chinese build

This branch builds an ARM64 Android APK with the RC1 Traditional Chinese (Taiwan) translation enabled by default.

- Target: `arm64-v8a`
- Default mode: Enhanced / Remastered
- Default language: `zh-tw`
- Translation source: `lming888/DBZ-SSD-zhTW`, tag `rc1`
- ROM and HD art pack are not bundled; select your own files in the Android setup screens.

The APK is produced by the GitHub Actions workflow `.github/workflows/android-zh-tw.yml`.
